# Omitted material

This minimal version uses an explicit inclusion list. Everything else stays private. The private preparation folder retains the detailed inventory and original path/hash mapping; publishing that inventory could itself expose private project information.

Omitted categories:

- All original databases, including the seven previously reviewed as containing experiment records. No database exception is needed for this first version.
- All raw nflverse/Tank01 feeds, raw source JSON, captured third-party HTML and research content. Twenty-five captured-source fingerprints are supplied through sanitized receipt metadata.
- All credential-related files, launchers, key stores, account/workspace identifiers, invoices, balances, funding notes, auto-recharge information and provider correspondence.
- All private email addresses, vendor quotes, correspondence PDFs and documents that contain them.
- Original internal documents and the full rights reconstruction. Short newly authored methods and data-source notes replace them.
- The critique of FantasyFootballBench and all basketball material.
- Vendored dependencies, images, screenshots, archives, original model responses, original source-code trees and all prior Git history.
- Optional draft cost estimates and account-level financial records.

PROVENANCE.json identifies the few original artifacts from which the public derivatives were calculated. The full omissions inventory, private backup and any broader original-history credential review are separate work; this package does not claim they are complete.

Additional source code, receipts or experiment records may be added only through another explicitly reviewed inclusion set. Never publish the original worktree or its branches as a shortcut.
